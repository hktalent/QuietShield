# QuietShield

住宅环境「噪声检测 + 前置摄像头录像」采集系统，纯浏览器运行，后端 Python 实时落盘。
反制震楼器相关技术：记录、监控、取证。

## 功能

- **噪声检测**（保留）：实时 dB、波形、超标事件日志（本地 + 后台 `/api/log`），按《噪声污染防治法》昼夜阈值（昼 55 / 夜 45 dB）。
- **前置摄像头录像**（新增）：网页 `getUserMedia` 拉取前置摄像头，`MediaRecorder` **分段独立录制**（每 30 秒 `stop()` 产出一段**完整可播**的 WebM），**实时分片上传**后台，断网最多丢一段；会话结束时后端用 ffmpeg 把本会话分片合并成**每 10 分钟一段的 MP4**。
- **设备指纹**：Canvas + WebGL + UA 等特征 SHA-256，作为每台设备的唯一标识（存 localStorage，跨刷新稳定）。
- **标签**：录像前可在界面输入标签（如"客厅""卧室"），标签作为录像文件名与噪声日志的组成。
- **文件名**：每段视频文件名为 `{标签}_{会话开始}_{本段开始}_{本段结束}_seg{序号}.webm`，时间均为 `YYYYMMDD_HHMMSS`（年月日时分秒），**始终含开始与结束标志**；会话结束合并为 `{标签}_{会话开始}_{会话结束}_第N段.mp4`。
- **多设备隔离**：后台按 `videos/<设备指纹>/` 建目录落盘，不同设备写入不同文件，互不冲突；同设备分片文件名带会话+序号，天然有序。
- **录像回看**：`/review.html` 按设备/标签/会话列出录像，**优先播放合并后的 10 分钟 MP4**，无 MP4 时回退到各分片。
- **布局**：主页「声压级」卡与「前置摄像头录像」区**同一行各占 50%**；声压计画布撑满卡片、dB 数字用视口单位随界面放大等比例缩放（不写死，自适应）。
- **单按钮启动**：点「开始监测」同时启动噪声监测与视频录制，停止一并停止；无独立「开始录像」按钮。
- **噪声样本回放**：界面「噪声事件日志」每行含**噪声录音播放 + 🔊×3 放大播放**（超标时自动录样本，未录则显示"—"）。
- **标签自动记忆**：录像标签输入后存浏览器 localStorage，同客户端下次打开自动回填，无需重输。
- **噪声日志来源标识**：`logs/noise_log_YYYY-MM-DD.html` 的「设备ID」列改为「录像标签」，显示标签内容、不再显示设备指纹哈希。

## 录像同时采噪声：为什么不冲突

浏览器中**一次** `getUserMedia({video, audio})` 拿到「音视频合并流」。同一路音频轨道可被**两个消费者并行读取**：

- `AudioContext.createMediaStreamSource()` → `AnalyserNode` → 实时噪声 dB 检测
- `MediaRecorder` → 录像（含声音）

合并流下双读不冲突。真正会冲突的是**两次分开的 getUserMedia**（一次纯音频、一次纯视频），在 iOS Safari 等移动端会因权限/流仲裁打架。本项目因此强制走合并流，噪声检测与录像可同时进行，无需降级。

> 已移除原「磁场」「振动」的监测、记录、日志功能及对应 UI/列。

## 目录结构

```
QuietShield/
├── Server.py        # HTTPS + 静态 + /api/log + 录像分片落盘 + /api/videos 清单
├── index.html       # 监测台页面
├── js/1.js          # 设备指纹 + 噪声检测 + 录像分片上传
├── css/1.css
├── review.html      # 录像回看页
├── videos/          # 录像分片（按设备指纹分目录，git 已忽略）
└── logs/            # 噪声事件日志（git 已忽略）
```

## 后端接口

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/log` | 噪声超标事件入库（含设备ID、标签） |
| POST | `/api/video/upload?deviceId=&tag=&start=&segStart=&segEnd=&segIndex=` | 二进制分片（原始 body），落盘 `videos/<deviceId>/{tag}_{会话开始}_{段开始}_{段结束}_segN.webm` |
| POST | `/api/video/finalize` | 写会话元数据（标签、起止时间） `<...>_meta.json` |
| GET | `/api/videos` | 按设备/标签/会话返回录像清单（含 webm 分片与合并的 mp4） |
| GET | `/videos/<deviceId>/<file>.webm` / `.mp4` | 播放分片或合并后的 MP4（正确 mime，支持中文名） |

## 运行

```bash
./start.sh   # 生成自签证书（仅首次）并启动 HTTPS 服务 0.0.0.0:8088
```

- 监测台：`https://<主机>:8088/`（需 HTTPS，摄像头/麦克风/定位才可用）
- 录像回看：`https://<主机>:8088/review.html`
