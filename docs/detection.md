# 震楼器检测：手机磁力计定位振动源

> 目标：不开门、不接触对方设备，用手机磁力计判定「头顶/脚下这块楼板是不是震楼器」，并留下可复现、可与噪声日志对齐的读数证据。
>
> 配套：[拦截篇 · Kali Wi-Fi 识别与阻断](interception.md) · [返回 README](../README.md)

## 1. 原理：为什么手机能测到

- 震楼器核心是**电磁铁 / 偏心电机**：线圈通电产生交变磁场，铁芯与永磁体带来**直流偏置磁场**。
- 地磁场约 **25–65 μT**，普通室内（钢筋、家电）一般 < 100 μT。
- 手机磁力计（霍尔 / AMR）量程多为 **±4900 μT**，读数单位 μT。
- 因此 **> 300 μT 属明显异常**，是强磁源近距离的标志；设备**移走或断电后读数回落到 60 以下**（接近地磁），这是最关键的判据。
- 偶极子磁场按 **1/r³** 衰减：距离拉大一倍，读数约降到 1/8，梯度极陡——所以「贴着楼板找峰值」定位非常有效。

### 读数判读表

| 合成读数 | 判读 | 处置 |
|---|---|---|
| < 60 μT | 正常（地磁基线） | 记录为基线 |
| 60–150 μT | 轻微抬升：音箱、电机、门磁、金属龙骨 | 关掉本房间可疑电器后复测 |
| 150–300 μT | 强可疑 | 加密网格，找峰值点 |
| **> 300 μT** | **高度疑似强磁源（震楼器 / 大功率电磁铁）** | 定点、拍照、与噪声时间对齐 |
| > 1000 μT 或接近满量程 | 几乎贴住磁源 | 记录点位，不要拆机 |

## 2. 器材与准备

| 项 | 要求 |
|---|---|
| 手机 | 带磁力计（绝大多数 Android / iPhone 均有），装「磁力检测」「Magnetic Field Detector」「Physics Toolbox Sensor Suite」类 App，需能显示**合成值 + X/Y/Z 三轴** |
| 手机壳 | **摘掉磁吸壳、MagSafe 卡包、指环支架、磁吸车载底座**，否则读数直接爆表 |
| 量具 | 卷尺、美纹纸/粉笔、手电 |
| 时间基准 | 同时打开本项目监测台（噪声 + 录像），作为统一时间轴 |

## 3. 操作流程

### 3.1 校准与基线

1. 站在房间中央，手机离墙 ≥ 1 m、离地 1.2 m，静置 10 s，记录合成值（正常 25–65 μT）。
2. App 若有「8 字校准」先做一次；刚开机或温差大时读数会漂，需静置回稳。
3. 记下基线数值与时间，后续所有判断都相对它。

### 3.2 网格扫描

4. 把可疑区域（天花板 / 地板 / 共用墙）划 **30–50 cm 网格**，用美纹纸编号。
5. 手机**背面（磁力计位置）紧贴被测面**，每点停 3–5 s，记录读数。
6. 先粗扫找「明显高于基线」的区域，再在该区域内把步长缩到 **10 cm** 做十字细化，直到找到峰值点。
7. 标记峰值点，拍照（含房间参照物、门牌），同一位置**重复测 3 次**并记录。

### 3.3 动态比对（最有力的证据）

8. 保持本项目噪声监测页运行，观察震楼器启停：
   - **启动**：噪声 dB 上升 + 磁场读数**阶跃上升并剧烈跳动**（交变场特征）
   - **停止**：噪声回落 + 磁场读数**回落到 60 以下**
9. 把磁场变化时刻与 `logs/noise_log_*.html` 的触发时间对齐，形成「同一时刻、两个独立传感器同时异常」的证据链。
10. 对方**拆移 / 换位置**后，回到原标记点复测：读数从 > 300 回到 < 60 → 确认该点位就是原振动源。

### 3.4 取证打包

- 点位照片（含房间 / 门牌参照物）、App 读数截图（带时间）或录屏
- 同一点位 3 次读数记录表：日期 / 时间 / 点位编号 / 读数（μT）
- 本项目导出的噪声日志 + 对应时段录像
- 建议整理成时间线：`时间 → 噪声 dB → 磁场 μT → 录像片段编号 → 事件`

## 4. 干扰与误判

| 现象 | 原因 | 处理 |
|---|---|---|
| 全屋都 > 300 μT | 磁吸壳、卡包、指环、磁吸支架 | 全部摘除后重测 |
| 局部高但噪声无变化 | 音箱喇叭磁体、冰箱/空调电机、配电箱、门磁、铁皮风管、钢筋密集处 | 断电或移开可疑电器后复测；钢筋本身不会产生 > 300 μT 的静磁场 |
| 读数一直漂 | 磁力计温漂 | 8 字校准后静置 1–2 min |
| 读数乱跳抓不住 | 交变场频率高于采样率（手机通常 10–100 Hz） | 用 App 的峰值保持 / 最大值记录，多次取最大 |
| 楼上没人也 > 300 | 电梯电机、水泵、UPS 等公共强磁设备 | 扩大扫描范围，向物业核实设备位置 |

> 手机磁力计**不是计量器具**，读数只能作为线索与辅助证据。正式维权建议配合有资质机构的噪声/振动检测报告。

## 5. 安全与边界

- 只测**自家范围内**可触及的表面；不入户、不拆对方设备、不损坏财物。
- 全程录像留存，避免与对方发生冲突。
- 向物业 / 公安 / 生态环境部门 / 法院提交时，附**原始读数与时间线**，不要只给一句「我测到 300」。

## 6. 与 QuietShield 的关系

本项目界面**不再内置**磁场/振动监测（早期版本有，已按需移除）。磁场定位采用「手机 App + 人工网格扫描」，把点位读数作为外部证据，与本项目产出的**噪声日志 + 录像**在同一时间轴合并归档，形成完整证据链。
